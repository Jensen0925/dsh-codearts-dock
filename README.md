# CodeArts Dock · 码道驿站

**在 DeepSeek Harness 中使用华为云码道模型，并在一处管理账号、积分和模型配置。**

> 第三方、非官方插件，与华为技术有限公司及 DeepSeek / DeepSeek Harness 的运营方**无任何关联**，未获其官方授权、认可或赞助。使用本插件需要你自己的合法账号和服务权限；模型调用可能消耗积分或产生费用，本插件不绕过计费。使用前请阅读 [免责声明](DISCLAIMER.md) 与 [安全说明](SECURITY.md)。

[GitHub](https://github.com/Jensen0925/dsh-codearts-dock) · [问题反馈](https://github.com/Jensen0925/dsh-codearts-dock/issues) · [MIT 许可](LICENSE)

## 能做什么

- **接入码道模型**：通过原生 LLM 适配器接入 Harness 的模型选择器，支持流式回复、推理输出和工具调用；图片输入取决于所选模型的能力。
- **多账号管理**：添加、重命名、导入、导出账号，手动切换当前使用的账号。
- **积分概览**：在输入框旁查看积分余额和账号列表，手动切换使用的账号。
- **账号健康检查**：显示余额不足、凭证或权限异常、限流、网络异常等状态及检查时间，支持重新检查和更新凭证。
- **模型筛选与预设**：按名称或 ID 搜索，筛选已启用、图片或推理模型，按倍率排序；保存模型配置预设，预览后应用。
- **配置备份与迁移**：备份模型选择、能力覆盖、预设等偏好；包含账号凭证时强制使用密码加密，恢复前先预览。
- **每日签到**：支持手动一键签到，活动是否可领取以上游返回为准。
- **诊断与反馈**：查看连接状态，复制经过字段筛选的诊断信息。

模型目录默认每五分钟刷新，显示的倍率来自上游。插件直接连接网关，不需要额外启动本地代理服务；保存模型选择后会通知 Harness 更新模型列表。

## 安装

需要已安装、支持第三方组合包（bundle）的 DeepSeek Harness，以及可访问码道服务的账号。

### 从 GitHub 安装

在 Harness 的插件管理页打开安装入口，输入：

```text
https://github.com/Jensen0925/dsh-codearts-dock.git
```

按宿主提示完成安装并启用插件。如宿主提示需要重启，完成一次重启后再打开设置页。

### 从 npm 安装

npm 发布完成后，可在同一安装入口输入包名：

```text
dsh-codearts-dock
```

请通过 Harness 的插件管理安装；在任意目录单独运行 `npm install` 不会自动启用 Harness 插件。

### 从插件索引安装

支持自定义插件索引的 Harness 版本可在「插件 → 发现」添加本项目的索引源，再查找 **CodeArts Dock**。索引地址与安装方式见 [发布说明](docs/PUBLISHING.md)。项目索引由本项目维护，不代表获得官方推荐或审核。

## 三步开始使用

1. 打开 **设置 → 码道 → 账号**，添加你的 Access Key ID（AK）与 Secret Access Key（SK），或导入凭证文件。
2. 在 **模型** 分栏启用需要的模型，调整图片开关、可关闭思考选项和默认推理强度，点击 **保存模型配置**。
3. 返回对话，在模型选择器里选择 `codearts` 对应的模型。输入框旁的积分胶囊可查看余额和账号。

不需要手动填写 STS 临时令牌：插件会为 AK/SK 交换临时凭证，并在需要时续期。账号或权限被撤销后，长期密钥也可能失效。

## 账号与凭证

插件依次尝试以下来源，优先采用通过检查的来源：

| 优先级 | 来源 | 配置方式 |
| --- | --- | --- |
| 1 | 环境变量 | 启动 Harness 前提供 `CODEARTS_AK`、`CODEARTS_SK`，可选 `CODEARTS_SECURITY_TOKEN` |
| 2 | 本机账号池 | 在设置页添加或导入 AK/SK，选择当前账号 |
| 3 | 本机码道客户端登录态 | 读取本机、本人已登录客户端中可用的临时凭证 |

环境变量优先于账号池。如果切换账号后使用的身份没有变化，请先检查是否设置了环境变量。

账号池支持华为云 `credentials.csv`、每行 `AK,SK` 文本，以及本插件导出的账号 JSON。导入前可预览，账号名称可以自行修改。账号池的普通导出包含**明文密钥**，不要发到 Issue、聊天或公开仓库；换机器时优先使用配置备份中的加密导出。

客户端登录态的可用性取决于客户端版本、登录状态和令牌有效期。插件只读取本机已有凭证，不代替官方登录；失效后需要在客户端重新登录。

## 设置与日常使用

### 账号、余额与健康状态

账号页显示各账号的积分、签到和健康状态。积分刷新失败时，当前界面会保留该账号上次成功读取的余额，并标注「上次结果」和更新时间；可重新检查或在输入框积分面板中重试。尚无成功记录时不显示估算余额。检查结果是最近一次请求的状态快照，不能保证下一次请求一定成功。

账号切换由你手动决定，目标账号会显示切换进度和结果；失败后可再次点击切换。已经发出的请求不会因为切换账号而自动重发。账号文件导入先展示完整名单和数量，确认后才会写入。

### 模型与预设

模型页可以搜索名称或 ID，筛选图片、推理能力，查看上下文、输出上限和积分倍率。点击模型名旁的星标可设为常用并置顶，点击即保存；搜索和筛选仍然有效，置顶分组内遵循所选排序。置顶仅影响插件模型设置页的顺序，不改变模型启用状态；常用列表随配置备份迁移。未启用的模型仍保留在目录里，便于重新开启。搜索、筛选和模型草稿在切换设置分栏时保留，模型配置修改在点击「保存模型配置」后生效。置顶保存结果与模型配置的未保存状态分别提示。

内置预设面向日常低倍率、深度推理和图片任务；也可以保存自己的预设。预设先应用到草稿，检查后再保存。手动打开图片或思考开关不会为上游模型增加它原本不支持的能力。

### Token 与上下文

Token 用量与上下文分析可通过 `dsh-context` 插件查看。本插件将上游返回的 Token 用量交给宿主，不另建本机用量账本。

### 签到

在账号页点击「一键签到」，为可领取的账号执行一次领取。仅在手动点击时执行，活动及领取结果以上游返回为准。

插件会在领取前检查活动，并记录本机尝试状态以减少重复请求。是否领取成功、奖励额度和到账时间以上游为准，不能保证在多设备并发操作时只发生一次尝试。

### 备份与迁移

在账号页展开配置备份：

1. 选择「导出配置」。默认只导出配置，也可以选择加密；包含账号凭证时必须设置并确认密码。
2. 在另一台机器选择「恢复配置」，打开备份文件。也可以展开「粘贴 JSON（高级）」直接粘贴备份内容。
3. 加密备份需要解密密码。先预览变更，确认无误后再恢复。

加密备份使用 scrypt 派生密钥与 AES-256-GCM。请妥善保存密码；本项目无法找回遗忘的密码。恢复会更新预览中列出的偏好和匹配账号的凭证。

## 数据与安全边界

- 模型请求会把你提交的对话上下文、附件及工具相关内容发送给配置的网关；请遵守上游服务规则及所在组织的数据政策。
- 为交换临时令牌、获取模型、查看积分或签到，插件会访问华为云 IAM 和码道服务。配置自定义网关后，请求及相关认证材料会发送到该地址。
- 本机凭证文件以明文保存，通过文件权限保护；加密备份不会加密运行中的凭证文件。
- 本机请求元数据不作为遥测上传。宿主、网关及你配置的其他组件可能有各自的数据处理行为。
- 复制诊断信息使用字段白名单；技术详情和你自行截取的日志仍可能含账号名称、路径或错误信息，提交反馈前请检查。

为兼容旧版，本机配置目录仍使用 `dsh-connect-codearts`：默认位于 `~/.config/dsh-connect-codearts/`，设置 `APPDATA` 时使用其下的同名目录；还兼容读取旧凭证文件 `~/.dsh-connect-codearts/credentials.json`。包名变更为 `dsh-codearts-dock`，模型 provider 仍为 `codearts`。

详细说明见 [SECURITY.md](SECURITY.md)。

## 常见问题

**安装后看不到设置页？**

确认插件已启用，查看 Harness 的插件加载错误；如安装过程提示需要重启，先重启再检查。不要同时启用新旧两个包来注册同一个 `codearts` provider。

**模型目录或积分加载失败？**

在账号页重新检查账号，在模型页重读目录，并查看诊断信息。优先检查网络、凭证、服务开通情况和权限。临时出现缓存目录不代表模型已经下架。

**为什么没有某个模型，或模型能力与预期不同？**

模型、价格、上下文和能力以上游接口及账号权限为准。本插件不保证某个模型长期可用，目录中的能力信息也可能滞后。

**出现限流或请求失败会自动换账号吗？**

不会自动切换账号。可查看健康状态并手动切换；部分请求错误会交由宿主的重试机制处理。

**去哪里反馈问题？**

请在 [GitHub Issues](https://github.com/Jensen0925/dsh-codearts-dock/issues) 提供 Harness 版本、插件版本、复现步骤和脱敏诊断。不要提交 AK/SK、令牌、明文账号导出或备份密码。安全问题按 [安全说明](SECURITY.md) 中的方式报告。

## 开发与验证

源码为直接运行的 ES 模块，无需构建浏览器包。使用 Node.js 安装依赖后执行：

```bash
npm install
npm test
```

离线测试覆盖协议、账号、注册、适配器和设置页交互。宿主 `BlockAssembler` 集成测试需要提供 `DSH_INSTALL_DIR`；真实网关测试单独通过 `npm run test:live` 运行，可能消耗真实账号的额度。

```text
src/          适配器、网关协议、账号、配置与备份
client.js     Harness 设置页与输入框积分胶囊
locale/       插件市场元数据
icons/        插件图标
docs/         详细介绍与发布说明
test/         离线测试及可选集成测试
```
