# CodeArts Dock · 码道驿站

**在 DeepSeek Harness 中使用华为云码道模型，并在一处管理账号、积分和模型配置。**

> 第三方、非官方插件，与华为技术有限公司及 DeepSeek / DeepSeek Harness 的运营方**无任何关联**，未获其官方授权、认可或赞助。使用本插件需要你自己的合法账号和服务权限；模型调用可能消耗积分或产生费用，本插件不绕过计费。使用前请阅读 [免责声明](DISCLAIMER.md) 与 [安全说明](SECURITY.md)。

## 能做什么

- **接入码道模型**：通过原生 LLM 适配器接入 Harness 的模型选择器，支持流式回复、推理输出和工具调用；图片输入取决于所选模型的能力。
- **多账号管理**：添加、重命名、导入、导出账号，手动指定当前使用的账号。
- **积分概览**：在输入框旁查看积分余额和账号列表，手动切换使用的账号。
- **账号健康检查**：显示余额不足、凭证或权限异常、限流、网络异常等状态及检查时间，支持一次检查所有账号和更新凭证。
- **模型筛选与配置**：按名称或 ID 搜索，筛选已启用、图片或推理模型，按倍率排序；手动调整模型配置，确认后保存。
- **签到与福利领取**：账号页可启用每天自动签到，在插件运行期间为全部已添加账号尝试领取可领取的每日签到活动；「一键签到」仍可手动领取其他合资格福利。
- **活动记录**：查看账号操作、配置变更、签到和连接状态的本机历史，按类型与结果筛选，支持刷新和清空。
- **诊断与反馈**：查看连接状态，复制经过字段筛选的诊断信息。

模型目录默认每五分钟刷新；在线目录中的倍率来自上游，刷新失败时可能使用缓存或内置数据，不能作为实时计费依据。插件直接连接网关，不需要额外启动本地代理服务；保存模型选择后会通知 Harness 更新模型列表。

## 安装

需要已安装、支持第三方组合包（bundle）的 DeepSeek Harness，以及可访问码道服务的账号。Node.js 与 Harness 的声明范围、验证方式见[兼容范围](docs/compatibility.md)。

### 从 GitHub 安装

在 Harness 的插件管理页打开安装入口，输入：

```text
https://github.com/Jensen0925/dsh-codearts-dock.git
```

按宿主提示完成安装并启用插件。如宿主提示需要重启，完成一次重启后再打开设置页。

### 从 npm 安装

在同一个安装入口输入包名：

```text
dsh-codearts-dock
```

请通过 Harness 的插件管理安装；在任意目录单独运行 `npm install` 只会安装文件，不会启用 Harness 插件。

### 从插件索引安装

支持自定义插件索引的 Harness 版本可在「插件 → 发现」添加本项目的索引源，再查找 **CodeArts Dock**。索引地址与安装方式见 [发布说明](docs/PUBLISHING.md)。项目索引由本项目维护，不代表获得官方推荐或审核。

## 三步开始使用

1. 打开 **设置 → 码道 → 账号**，添加你的 Access Key ID（AK）与 Secret Access Key（SK），或导入凭证文件。
2. 在 **模型** 分栏启用需要的模型，调整图片开关、可关闭思考选项、默认推理强度和上下文长度，点击 **保存模型配置**。
3. 返回对话，在模型选择器里选择 `codearts` 对应的模型。输入框旁的积分胶囊可查看余额和账号。

使用长期 AK/SK 时，不需要手动填写 STS 临时令牌：插件会交换临时凭证，并在需要时重新换取。账号或权限被撤销后，长期密钥也可能失效。

## 账号与凭证

插件按以下顺序解析凭证：

| 优先级 | 来源 | 配置方式 |
| --- | --- | --- |
| 1 | 环境变量 | 启动 Harness 前提供 `CODEARTS_AK`、`CODEARTS_SK`，可选 `CODEARTS_SECURITY_TOKEN` |
| 2 | 本机账号池 | 在设置页添加或导入 AK/SK，选择当前账号 |
| 3 | 本机码道客户端登录态 | 读取本机、本人已登录客户端中可用的临时凭证 |

长期 AK/SK 会先向 IAM 换取临时凭证，换取失败时继续尝试下一来源。已有临时令牌会直接使用，其有效性以上游请求结果为准；通过环境变量提供的临时凭证到期后，需要自行更新。

环境变量优先于账号池。如果切换账号后使用的身份没有变化，请先检查是否设置了环境变量。

账号池支持华为云 `credentials.csv`、每行 `AK,SK` 文本，以及本插件导出的账号 JSON。导入前可预览，账号名称可以自行修改。账号池的普通导出包含**明文密钥**，不要发到 Issue、聊天或公开仓库。

客户端登录态的可用性取决于客户端版本、登录状态和令牌有效期。插件只读取本机已有凭证，不代替官方登录；失效后需要在客户端重新登录。

## 设置与日常使用

### 账号、余额与健康状态

账号页显示各账号的积分、签到和健康状态。积分刷新失败时，当前界面会保留该账号上次成功读取的余额，并标注「上次结果」和更新时间；可在账号列表上方检查所有账号，或在输入框积分面板中重试。尚无成功记录时不显示估算余额。检查结果是最近一次请求的状态快照，不能保证下一次请求一定成功。

通过账号行「移除」左侧的「切换」按钮或输入框积分面板手动指定当前账号，选择在重启后保留。环境变量凭证仍优先于本机账号。批量检查、一键签到和每天自动签到面向全部已添加账号。

目标账号会显示切换进度和结果，失败后可再次点击「切换」。已经发出的请求不会因为切换账号而自动重发。账号文件导入先展示完整名单和数量，确认后才会写入。

### 模型配置

模型页可以搜索名称或 ID，筛选图片、推理能力，查看上下文、插件向宿主报告的输出上限和积分倍率。未启用的模型仍保留在目录里，便于重新开启。

搜索、筛选和模型草稿在切换设置分栏时保留；模型启用、能力开关、推理强度和上下文长度的修改在点击「保存模型配置」后生效。上下文下拉只提供不超过各模型目录上限的档位，并包含该模型的精确上限，选择「默认」恢复目录值。设置上下文长度后，插件向宿主报告的输出上限最多为所选上下文的四分之一，且不超过模型原输出上限；每个模型的「测试模型」按钮使用当前草稿发送简短请求，显示结果与耗时，会消耗少量积分。

手动打开图片或思考开关不会为上游模型增加它原本不支持的能力。

### Token 与上下文

Token 用量与上下文分析可通过 `dsh-context` 插件查看。本插件将上游返回的 Token 用量交给宿主，不另建本机用量账本。

### 签到与福利领取

账号页的「每天自动签到」开关默认关闭。启用后，插件运行期间会按本机日期每天为全部已添加账号尝试领取可领取的每日签到活动；插件关闭或未运行时不会执行，重新运行后会继续安排自动签到。开关不会自动领取学生福利、一次性活动等其他福利。

「一键签到」仍由你手动触发，会为全部已添加账号尝试领取签到及其他合资格福利。活动列表每次从上游读取。插件按当前接口规则，只尝试上游标记为可领取、且不是系统自动发放（`AUTO_GRANT`）的活动；学生认证等前置条件是否满足，由上游判断。一个活动已领或领取失败时，会继续处理其他活动。账号页显示领取进度，鼠标悬停可查看各活动的名称与状态。

插件会记录本机尝试状态；同一账号、同一活动在本机当天已有尝试记录时，批量操作会跳过，即使上次未成功。是否领取成功、奖励额度和到账时间以上游为准，不能保证多设备并发操作时只发生一次尝试。上游新增活动或改变领取流程后，仍可能需要更新插件。

### 活动记录

「活动记录」分栏按最新时间展示最近 200 条活动，包括账号变更、主动检查、模型配置保存、手动和自动签到、模型调用异常，以及模型目录的更新、异常和恢复。常规余额查询不记入历史，重复的目录刷新异常不会连续刷屏；同类模型调用异常每分钟最多记录一次，主动取消请求不记为失败。

记录保存在本机配置目录的 `activity.json`，重启后保留；可按活动类型、成功或异常结果筛选，也可清空。记录仅包含时间、操作类型、结果、数量和固定错误分类，不包含账号备注、密钥、令牌、网关地址、对话内容或原始错误文本。

## 数据与安全边界

- 模型请求会把你提交的对话上下文、附件及工具相关内容发送给配置的网关；请遵守上游服务规则及所在组织的数据政策。
- 为交换临时令牌、获取模型、查看积分或签到，插件会访问华为云 IAM 和码道服务。配置自定义网关后，请求及相关认证材料会发送到该地址。
- 本机凭证文件以明文保存，通过文件权限保护。自行备份本机配置目录时，请妥善保护备份介质。
- 本机请求元数据不作为遥测上传。宿主、网关及你配置的其他组件可能有各自的数据处理行为。
- 复制诊断信息使用字段白名单；技术详情和你自行截取的日志仍可能含账号名称、路径或错误信息，提交反馈前请检查。

本机配置默认位于 `~/.config/dsh-codearts-dock/`；设置 `APPDATA` 时使用 `$APPDATA/dsh-codearts-dock/`。从旧版 `dsh-connect-codearts` 升级时，账号、偏好和签到记录会自动沿用：先读取新目录，再尝试同一配置根目录下的旧目录 `dsh-connect-codearts/`，保存时写入新目录。

旧文件保留不动，回退旧版可继续读取升级前的数据；升级后的修改不会同步回旧目录，回退前请另行备份。更早的单条凭证文件 `~/.dsh-connect-codearts/credentials.json` 同样兼容读取。模型 provider 仍为 `codearts`。

本版移除内置及自定义模型预设，当前模型选择与覆盖设置继续沿用；保存偏好时会清理旧预设字段。旧版配置备份及加密备份不再提供恢复入口，账号迁移可使用账号页的导入、导出。

详细说明见 [SECURITY.md](SECURITY.md)。

## 常见问题

**安装后看不到设置页？**

确认插件已启用，查看 Harness 的插件加载错误；如安装过程提示需要重启，先重启再检查。不要同时启用新旧两个包来注册同一个 `codearts` provider。

**模型目录或积分加载失败？**

在账号页检查所有账号，在模型页重读目录，并查看诊断信息。优先检查网络、凭证、服务开通情况和权限。目录标注为缓存或内置数据时，不能据此判断模型是否已经下架。

**为什么没有某个模型，或模型能力与预期不同？**

模型、价格、上下文和能力以上游接口及账号权限为准。本插件不保证某个模型长期可用，目录中的能力信息也可能滞后。

**出现限流或请求失败会自动换账号吗？**

不会自动切换账号。可查看健康状态并手动切换；部分请求错误会交由宿主的重试机制处理。

**去哪里反馈问题？**

请在 [GitHub Issues](https://github.com/Jensen0925/dsh-codearts-dock/issues) 提供 Harness 版本、插件版本、复现步骤和脱敏诊断。不要提交 AK/SK、令牌或明文账号导出。安全问题按 [安全说明](SECURITY.md) 中的方式报告。

## 开发与验证

宿主侧插件源码位于 `src/`，通过 TypeScript 编译器输出为 `dist/` 中的 JavaScript ES 模块，由 Harness 加载。设置界面与输入框积分胶囊的代码位于 `client.js`，无需单独构建。开发环境使用 Node.js 和 pnpm：

```bash
pnpm install --frozen-lockfile
pnpm test
pnpm run typecheck
pnpm run build
```

离线测试覆盖协议、账号、注册、适配器和设置页交互。宿主 `BlockAssembler` 集成测试需要提供 `DSH_INSTALL_DIR`；真实网关测试单独通过 `pnpm run test:live` 运行，可能消耗真实账号的额度。发布前检查还会验证构建入口可导入，并扫描源码、文档、测试样例和最终 npm 包中的凭证特征与本机绝对路径。

```text
src/          宿主侧插件源码：适配器、网关协议、账号与配置
dist/         发布用的 JavaScript 模块，由构建生成
client.js     Harness 设置页与输入框积分胶囊
locale/       插件市场元数据
icons/        插件图标
docs/         详细介绍、发布说明与界面截图
screenshots.json  发布包截图清单
tests/        离线测试及可选集成测试
```
