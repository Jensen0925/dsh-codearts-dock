把**华为云码道（CodeArts Agent，也叫「码道」）**的模型接入 DeepSeek Harness (DSH)——
本插件与该产品**兼容**，但并非其官方组件。

原生 LLM 适配器**直连网关**：自签 `SDK-HMAC-SHA256`、P-256 密钥协商、SM4-GCM 载荷加密，
在宿主进程里完成整条链路——**没有本地桥接服务，不占端口，换模型不需要重启**。

---

## 它做什么

- **码道的模型出现在 DSH 的模型选择器里**：provider 路由叫 `codearts`，模型名后面带上游此刻给出的积分倍率（如 `GLM-5.3-Flash · 0.08x`）。
- **设置页在「设置 → 码道」**：三个分栏——凭证、模型目录、诊断。
- **输入框旁的积分胶囊**：只读余额，点开能看到账号、套餐与来源。
- **模型目录每 5 分钟从上游重读**：上游上新、调价、改上下文窗口都会自动跟上；倍率完全由上游给出，插件不写死也不猜。

## 安装（仅本机）

本项目为**个人自用**，未公开发布，仓库已删除。安装只针对本机这份目录：

本机这个 profile 用 **link 安装**指向这份源码，改动立即生效，不需要重新拉取：

```
~/.dsh/profiles/<profile>/node_modules/dsh-connect-codearts
  -> <本目录>
```

一次性的登记（若重建 profile 时需要重做）：

1. profile 的 `package.json` 里
   `"dsh-connect-codearts": "link:<本目录绝对路径>"`，并把它加入
   `dsh.profile.bundles`（顺序决定设置页里各卡片的位置）。
2. 建立上面的软链接。
3. **重启一次 DSH**（宿主启动时读取插件清单，改配置后必须重启）。

目录即插件包，不需要构建：源码是可直接运行的 ES 模块（`src/`），
浏览器端是 `client.js`（走 DSH 的 `__ModuleLoader__` 约定，无打包步骤）。

## 快速开始

### 1. 凭证：三种来源，任选一种

插件按下面的顺序找凭证，**每一条都会先验一次再采用**（只判断"文件存在"不够——
AK 被停用后文件还在、格式也对，用户会卡在一个永远用不了的来源上）。

| 顺序 | 来源 | 有效期 | 怎么来 |
|---|---|---|---|
| 1 | 环境变量 `CODEARTS_AK` / `CODEARTS_SK` | 永久 | 临时测试用 |
| 2 | 设置页填的 AK/SK | **永久** | 华为云控制台 → 我的凭证 → 访问密钥 |
| 3 | 码道客户端登录态 | 几小时 | **什么都不用做** |

#### 想一劳永逸 → 选第 2 种

在「设置 → 码道 → 凭证」里添加账号。只有 IAM 的 AK/SK 两项，**不需要填 STS**——
插件会自动换取临时令牌并在到期前续租。

**支持多个账号**：账号池里可以放任意多个华为云账号，请求用「当前」那个，
其余一键切换；每个账号单独显示积分与签到状态。

**支持导入**：粘贴华为云 console 下载的 `credentials.csv` 内容即可（按表头认列，
`User Name` 列会成为账号名），也可以每行一对 `AK,SK`，或贴本插件导出的 JSON。
「导出」把整个账号池输出成同样的 JSON，换机器时直接粘过去。



装好插件后在「设置 → 码道 → 凭证」填一次。只有 IAM 的 AK/SK 两项，
**不需要填 STS**——插件会自动换取临时令牌并在到期前 10 分钟续租。

也可以直接写文件（权限 `600`）：

```json
// ~/.config/dsh-connect-codearts/credentials.json
{ "ak": "HPUA...", "sk": "..." }
```

#### 想零配置 → 选第 3 种

本机装过码道客户端并登录过的话，插件会读取该客户端在本机保存的登录态，
借那份临时凭证直接用。这类凭证几小时后会失效，届时打开一次码道客户端即可恢复。

关于这条路径的边界，说明如下：

- 只读取**本机**、**你本人**已在官方客户端登录后的凭据，
  不会上传到任何服务器，也不会与其他机器或用户共享。
- 它不是「绕过登录」或「提权」：凭证由官方客户端签发，
  有效期由官方控制，过期后仍需你去客户端重新登录。
- 如果你没有安装或登录过该客户端，这条路径不会生效，
  插件会退回环境变量或凭证文件。
- 你可随时不启用它：只要能通过前两种方式提供凭证，插件就不会走到这里。

## 设置页里有什么

### 凭证

保存 / 测试连接 / 刷新 / 清除，加一个「当前生效的来源」；
「测试连接」会把 凭证 → 会话密钥 → 模型清单 → 积分 → 账号 全链路跑一遍并逐条报告结果。

### 每日签到

上游的每日签到是一个真实活动（`campaignId 34`「每日签到领100积分」，`MANUAL_CLAIM`）。
账号池里每个账号有自己的签到状态：可领时显示「签到」按钮，领过显示「今日已签」。

**默认不自动签到。** 打开「每日自动签到」后，插件每天替你签一次；它有三道护栏：

1. 领取前**重新读一次**上游状态，已签的跳过，不会重复领；
2. 按**本地日期**记录每个账号最后一次尝试，同一天的重试不会再打到上游；
3. 上游自己说不可领取时，**一次写请求都不发**。

签到花掉的是一份真实、不可撤销的权益，所以默认关闭；关闭状态下插件只读不写。

### 模型

表格列出上游此刻的完整目录：上下文窗口、输出上限、积分倍率、是否支持图片、思考档位。
**输出上限向宿主报的时候封顶 32768**，不是照抄上游的 65536——DSH 的压缩逻辑会把
`maxTokens` 和一份 headroom 一起从窗口里扣掉，照抄会让 20 万窗口的模型只剩约 7 万可用。

### 诊断

只读事实表，专门为了能整段贴进问题反馈：provider 路由、网关、凭证文件位置、
目录来源与错误、凭证错误，以及原始 JSON。

## 协议层（为什么这么写）

整条链路的每个参数都是对照真实网关的**公开行为**（请求与响应）确认过的，
实现目的是与该服务**互操作**；其中三条与常见假设相反：

| 项 | 实际值 | 说明 |
|---|---|---|
| 密钥协商曲线 | **P-256**（`prime256v1`） | 不是 X25519 |
| KDF | **裸 SHA256 截前 16 字节** | 不是 HKDF |
| 请求 AAD | `${method}\|${pathname}\|${ts}` | 与响应无关 |
| 响应分块 AAD | **`${keyId}\|${chunkIndex}`** | 与请求的 method/path/ts 无关——正是这一点让分块解密成立 |
| SM4-GCM | **纯 JS 实现** | 宿主 Electron 的 OpenSSL 只有 `sm4-cbc` 等，**没有 `sm4-gcm`** |

请求体不是 JSON 信封：密文以 **Base64 文本**放在 body，IV / tag / keyId / 时间戳走
`X-Encrypt-*` 头，`Content-Type: application/octet-stream`。响应是 `iv:tag:ciphertext`
三分块的 SSE，**没有 `data:` 前缀**——先解密再解析，顺序反了会静默丢掉每一帧。

另外两个坑写在代码注释里：`developer` 角色要降级成 `system`（网关对 `developer`
回的是空 200，不是报错），思考强度字段是 `reasoning_effort` 而不是 `strength`。

## 硬性约束

- **并发会话上限 3 个**（`TM.00001041`）。网关按 `user-session-id` 计会话数，
  所以插件固定复用同一个会话 id，并在每轮对话前后发 `heartbeat` 标 busy/idle，
  让名额及时释放。撞上了等 1–2 分钟让旧会话过期。
- **IAM 换 STS 有频率限制**，短时间反复换会 403，等约 1 分钟恢复。
- **图片走标准 OpenAI `image_url`**（data URL）。实测 8×8 纯蓝 PNG 带图答「蓝色」、
  不带图答不出来，确认图像真的被识别。码道客户端内部用的 `file` 格式网关**不认**。

## 测试

```bash
npm test        # SM4-GCM（含与 OpenSSL 字节级对照）、签名、密钥派生、SSE 解析、
                # 适配器（消息转换、块生命周期、工具调用、错误映射、usage 顺序）
```

在 DSH shell 里跑会额外执行组装器集成测试（`test/assembler.test.mjs`）：把适配器产出的
chunk 直接喂给宿主**真实的** `BlockAssembler`，断言文字、思考、工具参数与 usage 都还在——
`block-end` 的 `block` 会覆盖此前增量，这条链路必须用真实组装器验证，不能只看 chunk。

离线测试不需要凭证。要跑真实网关的端到端探针：

```bash
CODEARTS_AK=... CODEARTS_SK=... npm run test:live
```

## 已知限制

- 没有签到接口：`/snap-manager` 与 `/v1/ops` 下的候选路径实测全部 404。
  插件里保留的 `listBenefits` / `claimBenefit` 只对应上游确实提供的活动接口。
- 借码道登录态这条路依赖客户端把凭证写在可读位置；客户端换了存储方式就得跟着改。
- 本插件不提供账号、不共享凭据、不绕过计费：每次调用消耗的是**你自己账号**的额度。

## 目录

```
src/
  index.js        宿主入口：注册适配器、刷新目录、注册 HTTP 路由
  adapter.js      原生 LlmAdapter：消息转换 + 块生命周期
  gateway.js      网关客户端：签名 + 协商 + 加密请求 + 分块解密
  sts.js          IAM 永久 AK/SK → STS 临时凭证
  credentials.js  凭证来源、缓存与自动续期
  models.js       模型清单发现与合并
  catalog.js      活目录（适配器/设置页/诊断共用）
  account.js      积分、身份、福利活动（只读为主）
  protocol/
    sign.js       SDK-HMAC-SHA256
    crypto.js     P-256 + SM4 会话密钥
    sm4.js        纯 JS SM4-GCM
    sse.js        SSE 帧切分与解析
client.js         浏览器端：设置页 + 积分胶囊
```
