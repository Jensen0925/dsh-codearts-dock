# CodeArts Dock · 码道驿站

在 DeepSeek Harness 中接入华为云码道模型，管理多账号、积分和模型配置。

这是第三方非官方插件，与华为及 DeepSeek / Harness 运营方无官方关系。需要自己的有效账号和服务权限；调用可能消耗积分或产生费用。

## 功能

- 原生模型适配：流式文本、推理、工具调用，以及模型支持的图片输入。
- 多账号管理、导入导出、手动选择和全部已添加账号的健康检查。
- 本机活动记录：查看账号、配置、签到和连接状态事件，支持筛选、刷新和清空。
- 输入框积分胶囊及多账号余额概览，刷新失败时保留并标注上次结果。
- 模型搜索、能力筛选、倍率排序和配置草稿；支持在模型上限内设置上下文长度，并用当前草稿逐个测试模型，测试会消耗少量积分。
- 每天自动签到默认关闭；启用后仅在插件运行期间为全部已添加账号尝试领取每日签到，其他福利仍需手动触发。
- 手动一键领取：从上游福利列表实时发现当前可领活动（每日签到、Skill 创新赛等），为全部已添加账号逐项领取；仅尝试上游标记可领取且非自动发放的活动，认证等资格以上游为准。

## 开始使用

安装启用后，打开「设置 → 码道 → 账号」添加 AK/SK，在模型页启用需要的模型并保存，再从对话模型选择器选择对应模型。

## 数据与费用

请求内容及认证信息会发送给配置的服务；本机凭证以明文保存，普通账号导出包含密钥。请妥善保护凭证和自行制作的本机配置备份。余额和倍率不是官方账单，实际计费以上游为准。
