# CodeArts Dock

Connect Huawei Cloud CodeArts models to DeepSeek Harness and manage accounts, credits and model preferences.

An unofficial third-party plugin, unaffiliated with Huawei and DeepSeek / Harness operators. You need your own authorized account. Model requests may consume credits or incur charges.

## Features

- Native adapter for streaming text, reasoning, tool calls and model-supported image input.
- Multiple accounts, import/export, manual switching and actionable health checks.
- Composer credit chip and multi-account balance overview.
- Model search, capability filters, multiplier sorting, drafts and configuration presets.
- Configuration migration with mandatory password encryption when credentials are included, and a restore preview.
- Manual check-in for eligible accounts; availability and results depend on the upstream service.

## Get started

Install and enable the bundle, open Settings → CodeArts → Accounts, add your AK/SK, select and save the models you need, then choose a CodeArts model in a conversation.

## Data and costs

Requests and authentication information are sent to the configured services. Local credentials and ordinary account exports are plaintext; prefer encrypted backups for migration. Balances and multipliers are not official billing records.
